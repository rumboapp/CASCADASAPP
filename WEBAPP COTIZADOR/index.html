Ábrelo con un solo clic
Configuración de una sola vez en este computador.

El navegador, por seguridad, nunca puede ejecutar solo un archivo descargado. Pero se le puede dar permiso una única vez para los correos:

  1. Abre la barra de descargas del navegador (abajo o arriba a la derecha).
  2. Haz clic derecho sobre el archivo .eml recién descargado.
  3. Marca “Abrir siempre archivos de este tipo”.

Desde entonces, cada vez que aprietes el botón azul de Outlook el correo se abrirá directamente, sin pasos intermedios.
